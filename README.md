# Colony Conquest — indirme

Colony Conquest'in Android sürümü. Bu depoda kaynak kod yoktur; yalnız kurulum dosyaları burada yayımlanır.

İndirme sayfası: **https://colony.cantalay.com**

## Android'e kurulum

1. Telefonda şu bağlantıyı açın: **[ColonyConquest.apk](https://github.com/cantalay/colony-conquest-releases/releases/latest/download/ColonyConquest.apk)**
2. İndirme bitince dosyayı açın. Tarayıcı "bilinmeyen uygulamaları yükle" izni isterse verin.
3. **Yükle**'ye dokunun.

Android 8.0 ve üstü, 64 bit (ARM64) telefonlar gerekir. Yeni sürüm, eskisinin üstüne kurulur; ilerlemeniz silinmez.
Sürüm notları ve dosyanın SHA-256 özeti [Sürümler](https://github.com/cantalay/colony-conquest-releases/releases) sayfasındadır.
